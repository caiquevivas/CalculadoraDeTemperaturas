## Calculadora de Conversão de Temperaturas

Este projeto é uma calculadora simples feita em Java que converte temperaturas entre diferentes escalas:
**Kelvin**, **Celsius** e **Fahrenheit**.

## Funcionalidades

* Converter **Kelvin → Celsius**
* Converter **Kelvin → Fahrenheit**
* Converter **Celsius → Kelvin**
* Converter **Celsius → Fahrenheit**
* Converter **Fahrenheit → Celsius**
* Converter **Fahrenheit → Kelvin**

## Tecnologias usadas

* Java (versão 8 ou superior)
* Scanner (`java.util.Scanner`) para entrada de dados
